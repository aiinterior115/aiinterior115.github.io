# AI INTERIOR website

Static site, no build step, no dependencies. Upload everything in this folder to the repository root.

## Publish on GitHub Pages (free)
1. Open (or create, Public) the repository `aiinterior115.github.io`. Check existing files first and keep anything you need.
2. Upload index.html, style.css, script.js, 404.html, robots.txt, sitemap.xml and the images folder. Commit to main.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Live in 1 to 3 minutes at https://aiinterior115.github.io/

## Optional
- Enquiry form: put the WhatsApp number in script.js (WHATSAPP_NUMBER) to switch it on.
- Images in /images are illustrations. Replace any file with a real photo of the same name when you have one.
